# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **not** disclose it publicly through GitHub Issues.

Instead use **GitHub Private Vulnerability Reporting**or  report it privately by contacting the project maintainer with:

- A detailed description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

The maintainer will investigate the report and work on an appropriate fix before public disclosure.

---

## Scope

This project is intended for educational and research purposes.

Security reports related to:

- Authentication bypass
- Sensitive information exposure
- Remote code execution
- Dependency vulnerabilities
- Logic flaws affecting investigation accuracy

are appreciated.

---

Thank you for helping improve the security of this project.
